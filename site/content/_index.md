저는 인공지능 기술을 실제 사용자가 활용할 수 있는 웹서비스로 구현하는 데 관심이 있습니다. Connect6 AI 프로젝트를 통해 알고리즘을 구현하고 탐색 성능을 개선하는 과정을 경험했으며, 웹서비스 개발 프로젝트에서는 인증과 데이터 처리 등 서비스의 주요 기능을 직접 구현했습니다. 이러한 경험을 통해 인공지능 모델을 개발하는 것뿐만 아니라, 그 결과를 사용자에게 효과적으로 전달하는 서비스 개발에도 흥미를 갖게 되었습니다.

현재 인공지능과 웹 개발 관련 학습을 병행하며 문제 해결 능력과 서비스 구현 역량을 키우고 있습니다. 앞으로는 인공지능 모델의 구조와 동작 원리를 깊이 이해하고, 이를 실제 서비스에 적용하는 것이 목표입니다. 이를 위해 관련 논문과 구현 사례를 학습하고, Python 기반 모델을 직접 실행·검증한 뒤 API와 웹 화면을 연동하는 프로젝트를 단계적으로 진행할 계획입니다.
